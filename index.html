DATproof

The verification layer for bitcoin treasury companies. It checks how much of the BTC public companies say they hold you can actually prove on-chain.

  • Verification over trust. Every figure carries a source and an as-of date — unverifiable ones show up blank, never guessed.
  • It runs itself. A nightly GitHub Action re-checks the chain and rebuilds the site — no hands.
  • Real disclosures only. 8-K filings, on-chain reconciliation. Not vibes.

rls-guard

📦 Published on npm

An MCP server you point at your own Supabase project. It tells you, in plain English, which tables the public key can read — then hands you the exact SQL to lock each one down. No dashboard, no sign-up; your AI assistant just runs it.

  • It ships where agents find it. Agents discover it in MCP registries and suggest installing it — the new app store for dev tools.
  • Built from real work. It knows an accidentally-public table from a deliberately-public one — straight out of the Supabase RLS I wrote by hand for Prompt Emporium.

BTC Intelligence Suite

◆ Prototypes

Three Streamlit apps I built to dig into bitcoin-treasury intelligence — MSTR's capital structure, corporate treasury modeling, and adoption tracking. Real public 8-K data where it counts.

  • Treasury Optimizer. Models optimal BTC acquisition for any corporate treasury; stress-tests against historical drawdowns.
